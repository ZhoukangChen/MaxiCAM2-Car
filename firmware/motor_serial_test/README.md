# NUCLEO 串口触发的短脉冲电机测试

此临时固件用于逐路验证 AT8236 和减速电机。启动后 AIN1、AIN2、BIN1、BIN2 全部保持低电平；只有在 ST-LINK 虚拟串口收到 `ARM` 后的 5 秒内收到 `A` 或 `B`，才会让相应一路短时正转 200 ms，随后立即把四路恢复为低电平。未经 `ARM` 的命令不会驱动电机。根据实测方向，右侧 MOTOR-A 使用 AIN2=1、AIN1=0；左侧 MOTOR-B 使用 BIN1=1、BIN2=0。

## 接线映射

- `AN1 / AIN1` → `D3 / PB3`
- `AN2 / AIN2` → `D4 / PB5`
- `BN1 / BIN1` → `D5 / PB4`
- `BN2 / BIN2` → `D6 / PB10`
- `GND` → NUCLEO `GND`

USART2 使用 NUCLEO 默认的 ST-LINK 虚拟串口：`PA2/TX`、`PA3/RX`，115200 baud、8N1。串口应先收到 `MOTOR_TEST_READY; outputs low`。

## 安全使用

烧录前关闭稳压板和 AT8236；为增加隔离，可先拔下电机输出线。NUCLEO 保持 Mini-USB 供电，通过 ST-LINK 的 Connect Under Reset 烧录。点动前将车体稳定垫起、让两个驱动轮离地；一次只发送一个通道命令。不得堵转电机。每次点动后四个控制输入都会回到低电平。

## 2026-11-21 台架实测

- AT8236 VM 端实测 10.37V，电池实测 12.67V；没有把电池直接接到 VM。
- MOTOR-A 是右轮，最初 AIN1 驱动时向后。因电机线是一体插头，未交换电机线；测试固件改用 AIN2 驱动后，用户确认向前。
- MOTOR-B 是左轮，BIN1 驱动时向前；修改后与右轮方向一致。
- 两轮在架空状态分别点动 200ms，测试后输入回到低电平。没有验证持续负载、PWM 调速或编码器闭环。

这是一份临时测试固件，会暂停 MaixCAM2 UART 和循线程序。后续正式控制程序须保留 MOTOR-A 的反向映射，并将电机控制并入视觉 / 循迹主程序。
