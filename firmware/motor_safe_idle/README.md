# NUCLEO 电机安全待机固件

此固件用于检查和建立 AT8236 控制输入的待机状态，不会驱动电机，也不会读取循线板或处理 MaixCAM2 串口。

## 控制脚

- `D3 / PB3` → `AN1 / AIN1`
- `D4 / PB5` → `AN2 / AIN2`
- `D5 / PB4` → `BN1 / BIN1`
- `D6 / PB10` → `BN2 / BIN2`

启动后，四个控制脚配置成低速推挽输出低电平，并保持待机。AT8236 的 `IN1=0、IN2=0` 对应滑行/休眠。

## 构建

在此目录运行 `./build.sh`。生成文件放在 `build/`，由本目录 `.gitignore` 忽略。

## 使用边界

这是临时安全待机固件，不是小车运行固件。NUCLEO 复位到程序执行初始化之间仍有硬件复位状态；若要求复位期间也保持确定低电平，应在 AT8236 四个逻辑输入上使用合适的外部下拉，并先确认驱动板上没有已安装的下拉电阻。加载此固件前应先关闭电池动力支路并拔下电机线。
