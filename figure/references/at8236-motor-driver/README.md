## 商家资料中标注的参数

- 电机驱动芯片：AT8236；VM 供电范围：5–17 V。
- 双路输出：单路额定驱动电流 3 A，单路峰值电流 6 A。
- 逻辑输入电压：0–5.25 V；PWM 输入频率：0–100 kHz。
- 板载电源输出包括 VM、5 V、3.3 V；商家标注 5 V 输出电流为 3 A。
- 具有输入反接保护，以及驱动芯片过流、短路、欠压和过温保护。

## 本车实物核对与台架结果

- 手中 AT8236 板端丝印为 DC 5–12V，Yahboom 官方产品页也列 5–12V；与商家参数截图中的 VM 5–17V 冲突。未获得该板版本的厂家澄清前，按 12V 上限处理。
- YB-MVP01 的 VADJ 输出设为 10.37V，AT8236 蓝色 VM 输入端实测 10.37V；已用该电压完成两路架空短脉冲测试。
- 右轮接 MOTOR-A，左轮接 MOTOR-B。由于一体式电机插头不便换序，右轮前进方向由测试固件改用 AIN2；左轮前进使用 BIN1。
- 以上点动只验证短时方向，不等于 3A 连续电流、6A 峰值、长时间热稳定性或堵转保护已通过。
