## 商家资料中标注的参数

- 工作电压：5 V；工作电流：85 mA。
- 线宽检测范围：0.5–6 cm；检测高度：5–60 mm。
- 输出：8 路 IO、I2C、UART；数字和模拟信号。
- 板尺寸：91.11 × 36.50 × 13.50 mm。
- 安装孔支持 M2.5 或 M3 铜柱/螺丝；槽孔间距标注为 16–42 mm。
- 资料标注了 5V 输入反接保护、IO 限流和静电保护。

## 本车接线与测试记录

- 使用 I²C 4 线接口：`5V → NUCLEO 5V`、`GND → GND`、`SCL → D15/PB8`、`SDA → D14/PB9`。
- 此前已完成黑白校准：白底读数为 `0xFF`，黑带横扫时八路均出现响应。
- 2026-11-21 用户报告把四根线接回；当前电机测试固件不扫描 I²C，复接后的总线读数待重测。赛道循迹算法和实场表现仍未验证。

以上为商家标称参数与本车记录。后续每次改接后都重新检查 5V/GND/SCL/SDA 顺序及 I²C 响应。
