# 早期效果图归档

当前网页使用 `figure/assembly-layout-3d-v6.png` 和 `figure/vision-simulation-route-recognition-v5.png`。旧单层总装图和旧单层三视图保存在本目录；双层版本位于 `figure/` 根目录并显示在组装布局页。

`qa-vision-composite.svg` 与 `qa-vision-composite-v3.svg` 依赖本目录中的同名视觉帧和叠加图；相关文件一并归档，以保留原有相对引用。
