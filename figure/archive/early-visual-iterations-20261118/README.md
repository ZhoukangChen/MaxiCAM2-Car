# 早期效果图归档

此目录保存已被当前网页版本替代的早期装配图、车型概念图和视觉模拟迭代稿。文件仅从 `figure/` 当前素材目录移入归档，没有删除。

当前网页使用 `figure/assembly-layout-3d-v7.png` 和 `figure/vision-simulation-route-recognition-v5.png`。本目录还保存旧单层图、错误前后轮布局的 v6 总装图，以及方向未对齐的旧俯视图；当前双层三视图位于 `figure/` 根目录并显示在组装布局页。

`qa-vision-composite.svg` 与 `qa-vision-composite-v3.svg` 依赖本目录中的同名视觉帧和叠加图；相关文件一并归档，以保留原有相对引用。
